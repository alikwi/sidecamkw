# SideCam — V1

Static front-end prototype for sidecamkw.com.

## Current V1
- Cinematic dark sports visual direction
- Responsive homepage
- Player search demo
- Latest matches section
- Featured clips section
- Clip preview modal
- "How SideCam works" section
- Mobile navigation
